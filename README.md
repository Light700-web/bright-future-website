# Bright Future Technologies Limited Website

**Student:** Oguejiofor Oluebube Victor

## Project description
A five-page business website for Bright Future Technologies Limited, a company offering computer training, web development, data analysis, graphics design, cybersecurity training, IT consultancy and computer repairs.

## Objectives
- Build a structured HTML5 website with semantic elements.
- Link pages with a consistent navigation menu.
- Use images, lists, tables and a contact form.
- Style the site with an external CSS file, the box model, Flexbox and a media query.
- Publish the site with GitHub Pages.

## Technologies used
HTML5, CSS3, Git and GitHub Pages. No JavaScript or frameworks.

## Pages
index.html (Home), about.html (About Us), services.html (Our Services), training.html (Training Programmes), contact.html (Contact Us)

## Features developed
- Shared header, navigation and footer on every page
- Hover and focus effects on links and buttons
- Seven services in a Flexbox layout
- Course fees and timetable in an HTML table
- Contact form (text, email, tel, date, select, textarea) and embedded Google Map
- Responsive layout for mobile screens

## Challenges encountered
1. Image paths failed on GitHub Pages.
2. The contact form cannot send messages without a backend.
3. The navigation had to fit small screens without JavaScript.

## How the challenges were resolved
1. Used lowercase file names and relative paths with forward slashes.
2. Kept the form as a front-end demonstration, as the brief allows.
3. Used Flexbox wrapping and a media query to stack the menu on mobile.
